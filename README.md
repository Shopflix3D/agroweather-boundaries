# AgroWeather Live administrative boundaries

Country-level files generated from **geoBoundaries gbOpen**.

The files represent different administrative units across countries; ADM2 does not always mean municipality. Some countries have no ADM2/ADM3.

The app reads `manifest.json`, `world/ADM0.geojson`, and `countries/{ISO3}/{ADM}.geojson` through raw.githubusercontent.com.
